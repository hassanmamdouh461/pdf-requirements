## 🌟 نظرة سريعة على ما يقدمه التطبيق

### 1. ماذا يقدم التطبيق للطالب؟
- **موجود عندنا بس (نقاط تميز حصرية):**
  - **زر «أنا جاهز»:** تحديد المحطة وظهور إشعار مباشر للسائق على الخريطة.
  - **رحلة أقصر وتخطي المحطات الخالية:** تنبيه السائق بعدم الوقوف في محطات لا ينتظر بها أحد.
  - **مساعد الذكاء الاصطناعي (AI):** تحليل جدول الطالب الدراسي واقتراح أنسب مواعيد الذهاب والعودة تلقائياً.
  - **مشاركة الرحلة مع الأهل:** رابط تتبع مباشر يعمل عبر واتساب للمتصفح بدون الحاجة لتثبيت التطبيق.
  - **توقع الازدحام بمساعدة الـ AI:** تنبيه استباقي ذكي بمساعدة الـ AI بناءً على متوسط الإشغال التاريخي لتفادي نفاد المقاعد.
  - **فاتك الموعد؟ بديل فوري:** اقتراح أقرب رحلة قادمة بها مقاعد شاغرة مع زر حجز مباشر.
- **الأساسيات والمميزات القياسية:**
  - خريطة حية للحافلة مع مسار السير الفعلي ووقت الوصول المتوقع (ETA) الدقيق.
  - حجز المقاعد وقائمة انتظار ذكية عند اكتمال الرحلة.
  - بطاقة ركوب رقمية بالـ QR Code للتحقق السريع ومنع التزوير أو تداول الكارنيهات.
  - إشعارات مخصصة وموجهة للطالب فقط، مع زر طوارئ SOS.
  - دفع الاشتراكات إلكترونياً (شهري، تذاكر فردية، اتجاه واحد).
  - تقييم الرحلات والسائقين وتقديم البلاغات والشكاوى.

### 2. ماذا يقدم التطبيق للسائق؟
- **واجهة عمل مبسطة للغاية (زرين فقط):** «ابدأ الرحلة» و «أنهِ الرحلة».
- **بث الموقع التلقائي:** يعمل فقط خلال وقت الرحلة لحماية الخصوصية وتوفير البطارية.
- **تحديث مرحلة الرحلة تلقائياً:** عبر نظام الـ GPS دون الحاجة لأي تشتيت أثناء القيادة.
- **خريطة الطلب والمحطات:** إيضاح عدد الطلاب المنتظرين عند كل محطة بأيقونات واضحة دون كشف بياناتهم الشخصية.
- **تخطي المحطات الفارغة:** كارت "وفّر وقت" لتنبيه السائق بالمحطات التي لا تتطلب وقوفاً.
- **مسح QR + عداد لحظي للركاب:** تسجيل سريع للركوب والتحقق الفوري مع كشف ركوب يدوي احتياطي.
- **جدول رحلات اليوم:** عرض منظم لرحلاته التالية وتفاصيلها.
- **شات داخلي مدمج وبلا اتصالات هاتفية:** للتواصل عند الضرورة فقط.

### 3. ماذا يقدم التطبيق للإدارة؟
- **نشر ومراجعة رحلات اليوم بضغطة واحدة:** إمكانية التعديل، تغيير السائقين، أو إضافة حافلات إضافية للخطوط المزدحمة.
- **مرونة تامة في إدارة الرحلات:** تعديل، إلغاء، أو إضافة رحلات منفردة حسب الطلب.
- **لوحة متابعة الطلب المباشر:** إلغاء أو دمج المواعيد الضعيفة تلقائياً وإخطار المشتركين فوراً بالبديل.
- **متابعة حية للأسطول والتشغيل:** مراقبة جميع الحافلات، نسب التقدم، عدد الركاب، والتحديثات اللحظية.
- **إدارة الاشتراكات والتحصيل المالي:** ضبط الخطط والمدفوعات الإلكترونية لمنع التهرب وحماية إيرادات الخدمة.
- **تقارير تفصيلية قابلة للتصدير (PDF / Excel):** أعداد الركاب، نسب الالتزام، التقييمات، والقرارات التشغيلية المبنية على الأرقام.
- **نظام متابعة الشكاوى والبلاغات:** متابعة البلاغات بحالاتها (مفتوح / مغلق) وتعيين المسؤولين عنها.
- **حماية الخصوصية وتثبيت السياسات:** حماية بيانات الطلاب ونشر لوائح الركوب والمواعيد مركزياً داخل التطبيق.
